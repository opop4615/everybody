# 호가전쟁 (Godot)

매수세와 매도세가 호가창에서 싸운다. 나는 한쪽 진영에 합류해 돌격하고, 벽을 쌓고,
차트 패턴이 완성되는 순간 스킬을 날린다. 게임 규칙 전체는 [`docs/orderwar.md`](../docs/orderwar.md).

![전투 화면](../docs/orderwar-godot.png)

## 실행

1. [Godot 4.4 이상](https://godotengine.org/download) 에디터에서 **가져오기**로 `godot/project.godot`을 연다.
2. **F5** (실행). 기본 해상도 1600×900, 창 크기에 맞춰 늘어난다.

Godot 4.4.1과 4.7.2에서 테스트했다. 렌더러는 Compatibility(OpenGL)라 웹·모바일 내보내기도 가능하다.

## 화면 구성

| 위치 | 내용 |
| --- | --- |
| 위 | 종목·시계·현재가, 매수세 vs 매도세 줄다리기(최근 20분 체결 비중), 체결강도, 일시정지·배속 |
| 왼쪽 | **호가창** (칸을 누르면 그 가격에 주문), 평가손익, 수량·돌격·벽 쌓기·포지션 정리·주문 취소 |
| 오른쪽 | **전투 공간**: 호가 한 칸 = 전장 한 열, 그 칸의 잔량 = 거기 서 있는 병력 |
| 전장 아래 | 스킬 카드 손패 (Q·W·E), 방금 한 행동의 결과 |
| 맨 아래 | 5분봉 차트(MA5·MA20·기준가), 전장 소식(뉴스·공시·스킬 로그) |

전투 공간에서는:

- 가운데 **전선**이 현재가다. 왼쪽이 매수 잔량(매수군, 빨강), 오른쪽이 매도 잔량(매도군, 파랑). 내 주문은 금색 병사와 '나' 깃발.
- 시장가 주문은 뒤에서 달려와 전선에 부딪히는 돌격대. 기관·외국인·세력 같은 큰 물량은 이름이 뜬다.
- 공시가 세운 벽(합병 매수청구가, 유증 신주 물량, 자사주, 스킬 벽)은 **성벽**으로 선다.
- 스킬은 진영 색 **파도가 한 방향으로** 전장을 가로지르고, 몇 호가를 뚫었는지 보여준다.
- 맨 위 띠는 하한가(매수군 본진)부터 상한가(매도군 본진)까지의 **전황도**: 기준가, VI 관문, 내 평단, 전선 위치.
- 뉴스 속보와 적 스킬 경고는 전장 위쪽 띠로, VI(휴전)·상한가 사수 카운트는 전장 가운데에 뜬다.

## 조작

| 키 | 행동 |
| --- | --- |
| A | 돌격 (진영 방향 시장가) |
| S | 벽 쌓기 (아군 최우선 호가에 지정가) |
| D | 포지션 정리 |
| F | 주문 취소 |
| Q · W · E | 스킬 카드 1·2·3 |
| 1 ~ 4 | 수량 10% · 25% · 50% · 100% |
| Space | 일시정지 |
| 호가창 클릭 | 그 가격에 지정가 (상대 호가를 누르면 그 가격까지 즉시 체결) |

## 구조

| 폴더 | 내용 |
| --- | --- |
| `core/` | 게임 규칙. Node를 쓰지 않는 순수 로직(`RefCounted`)이라 헤드리스로 테스트된다 |
| `core/battle_engine.gd` | 한 판의 시뮬레이션: NPC 주문 흐름, 뉴스, VI, 패턴→스킬, 승패, 계좌 |
| `core/order_book.gd` | 가격·시간 우선 체결 호가창 |
| `core/chart_patterns.gd` | 12개 차트 패턴 판정 (하락 패턴은 뒤집은 차트에서 상승 패턴으로 판정) |
| `core/skill.gd`, `core/market_event.gd` | 스킬 표, 뉴스·공시·매크로·세계정세 덱 |
| `ui/` | 로비, 전투 화면, 호가창·전투 공간·차트 위젯 (모두 코드로 구성) |
| `scenes/main.tscn` | 시작 장면 (로비 ↔ 전투 전환) |
| `tests/` | 헤드리스 테스트 |
| `tools/` | 밸런스 시뮬레이터, 화면 캡처 |

엔진은 앱(Flutter) 쪽 `lib/game/`의 Dart 엔진을 그대로 옮긴 것이라 규칙과 튜닝 값이 같다.

## 테스트·도구

```sh
godot --headless --path godot --import                                  # 처음 한 번
godot --headless --path godot --script res://tests/run_tests.gd         # 34개 테스트
godot --headless --path godot --script res://tools/balance_sim.gd -- 100  # 종목당 100판 밸런스
godot --path godot --resolution 1600x900 --script res://tools/capture.gd -- <폴더>  # 화면 캡처
```
