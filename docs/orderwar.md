# 호가전쟁 (Order Book War)

> 매수세와 매도세가 호가창에서 싸운다. 나는 한쪽 진영에 합류해 돌격하고, 벽을 쌓고,
> 차트 패턴이 완성되는 순간 스킬을 날린다.

앱 하단 탭 **호가전쟁**에서 플레이한다. 한 판은 가상 종목의 하루 장(09:00~15:30)이고,
0.5초가 장중 1분이라 약 3분 15초면 끝난다 (2배속 가능).

## 핵심 루프

1. 로비에서 오늘의 전장(가상 종목)을 보고 **매수군** 또는 **매도군**에 합류한다.
2. 장이 열리면 NPC 개미·기관·외국인·세력이 호가를 주고받고, 뉴스·공시가 수시로 터진다.
3. 나는 내 계좌(1억)로 **돌격**(시장가)하거나 **벽**(지정가)을 쌓아 전선을 민다.
4. 5분봉에서 차트 패턴이 완성되면 그 방향 진영이 **스킬**을 얻는다.
   아군 패턴이면 내 손에 카드가, 적 패턴이면 3분 뒤 적 스킬이 날아온다.
5. 장 마감 종가 또는 상·하한가 안착으로 승패가 갈리고, 내 손익과 전공으로 등급(S~C)이 나온다.

## 승리 조건

| 조건 | 결과 |
| --- | --- |
| 종가 > 기준가 | 매수군 승리 |
| 종가 < 기준가 | 매도군 승리 |
| 상한가를 10분 지킴 | 매수군 즉시 완승 |
| 하한가를 10분 지킴 | 매도군 즉시 완승 |

진영이 이겨도 내 계좌가 깨지면 등급은 낮다: S = 승리 + 수익률 5% 이상, A = 승리 + 수익,
B = 승리 또는 수익, C = 둘 다 실패.

## 전장 규칙 (실제 한국 시장 규칙을 따름)

- **호가가격단위**: 2023년 개편 KRX 기준 (2,000원 미만 1원 … 50만원 이상 1,000원).
- **가격제한폭**: 기준가 ±30%. 상한가 위·하한가 아래로는 주문이 없다.
  상·하한가에서 못 받은 물량은 그 가격에 잔량으로 쌓인다.
- **정적 VI**: 직전 단일가 대비 10% 움직이면 2분간 단일가 매매.
  게임에서는 시장가·스킬이 봉인되고 벽 쌓기만 가능한 **휴전** 구간이다.
- 색은 국내 관례대로 상승·매수 빨강, 하락·매도 파랑.

## 플레이어 행동

| 행동 | 설명 |
| --- | --- |
| 돌격 | 진영 방향 시장가. 상대 호가를 먹어 치운다 (매도군은 공매도) |
| 벽 쌓기 | 아군 최우선 호가에 지정가. 적 돌격·적 스킬을 받아낸다 |
| 호가 탭 | 그 가격에 지정가. 상대 호가를 누르면 그 가격까지 돌격 |
| 포지션 정리 | 보유분을 시장가로 청산 |
| 주문 취소 | 미체결 전부 취소 |
| 스킬 카드 | 탭하면 발동. 30분 안에 안 쓰면 소멸, 최대 3장 |

주문 한도는 순자산 1배 (미체결 포함). 수량은 10/25/50/100% 중 고른다.

## 차트 패턴 = 스킬

스킬은 진영 병력이 **한 방향으로** 시장가 물량을 쏟아붓는 공격이다. 위력은
'표준 호가 잔량 몇 칸 분량'이라서 상대가 두껍게 쌓은 벽에 막히면 덜 나간다.
그래서 적 스킬 경고가 뜨면 벽을 쌓는 것이 대응이다.

| 매수군 패턴 | 스킬 | 위력 | 매도군 패턴 | 스킬 |
| --- | --- | --- | --- | --- |
| 상승장악형 | 장악 돌파 | 6 | 하락장악형 | 장악 붕괴 |
| 망치형 | 망치 방패 | 3 + 매수벽 6 | 유성형 | 유성 낙하 |
| 적삼병 | 삼병 돌격 | 4 × 3분 | 흑삼병 | 삼까마귀 급강하 |
| 골든크로스 (MA5↗MA20) | 골든 브레이크 | 10 | 데드크로스 | 데드 슬래시 |
| 쌍바닥(W) 넥라인 돌파 | W 반격 | 11 + 매수벽 5 | 쌍봉(M) | M 폭격 |
| 역헤드앤숄더 넥라인 돌파 | 넥라인 붕괴 (궁극기) | 9 × 2분 | 헤드앤숄더 | 목 베기 |

- 판정은 방금 마감된 5분봉 기준이며, 쌍바닥·헤드앤숄더의 기준(바닥 높이 차, 넥라인 높이)은
  최근 봉 평균 고저폭(ATR)에 맞춰 종목 변동성과 무관하게 동작한다.
- 하락 패턴은 가격축을 뒤집은 차트에서 대응하는 상승 패턴을 찾는 방식으로 판정한다.
- 같은 패턴은 6봉(30분) 안에 다시 발동하지 않는다.

## 전장 이벤트

이벤트는 시장 심리, 즉시 물량(shock), 지속 물량(pressure), 변동성, 호가벽을 바꾼다.

| 분류 | 예시 | 효과 |
| --- | --- | --- |
| 공시 | 주주배정 유상증자 | 심리 급랭 + 매도 물량 + 위쪽 신주 물량벽 |
| 공시 | 제3자배정 유상증자 (대기업) | 오히려 호재 |
| 공시 | 무상증자 1:1 | 권리락 착시 기대, 개미 매수세 지속 |
| 공시 | 흡수합병 / 합병비율 논란 | 변동성 확대 / 주식매수청구가(-6%)에 거대한 매수벽 |
| 공시 | 자사주 취득·소각, 블록딜, CB 발행 → 전환청구 | 지지벽, 대량 매물, 오버행 |
| 루머 | 피인수설 → 15분 뒤 조회공시 답변 | "검토 중"(호재) 또는 "사실무근"(악재) |
| 속보 | 기술이전 결과 발표 임박 → 20분 뒤 성사/결렬 | 긴장 구간 후 대박 또는 투매 |
| 매크로 | 연준 빅컷, CPI 쇼크, 환율 1,450원, 사이드카 | 시장 전체 심리 |
| 세계정세 | 중동 충돌, 미·중 협상, 엔캐리 청산 | 심리 + 변동성 |

종목과 뉴스는 모두 가상이다.

## NPC 시장 모델

- **LP(유동성 공급)**: 현재가 위아래 10호가에 잔량을 채운다. 쏠림이 있으면 불리한 쪽
  호가가 얇아진다 (호가 공백).
- **공격 주체**: 개미(소량·다수), 기관, 외국인, 세력(드물지만 대량)이 시장가로 친다.
- **쏠림(bias)** = 뉴스 심리 + 추세 추종(최근 10분 움직임) + 느린 분위기 변화
  − 가치투자자의 되돌림(기준가에서 멀어질수록 반대 매매).
- 심리는 매 분 3%씩 식는다.
